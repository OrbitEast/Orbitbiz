ORBITBIZ · SECURITY

Security is part of the product.

OrbitBiz is designed around authenticated business workspaces and business-scoped access to operational data. Security is an ongoing engineering responsibility, not a claim that a product is permanently risk-free.

Authentication

OrbitBiz uses authenticated access for the private business workspace. Public product information remains separate from private business records.

Business-scoped data

Business data is associated with the relevant business workspace and protected through database access policies and membership checks.

Application validation

Business workflows use application and database validation around important state changes and transactional operations. This helps prevent invalid workflow transitions and keeps related records connected.

Infrastructure

The application uses Supabase for authentication and PostgreSQL-backed application data, with Firebase Hosting delivering the web application.

What this page does not claim

OrbitBiz is pre-launch. This page does not claim a security certification, independent audit, penetration-test result or guarantee against every possible security incident. Such claims will only be published if they become factually supported.

Security is ongoing

Authentication, authorization, database policies, validation, transactional workflows and deployment configuration are reviewed as OrbitBiz grows. The public security information will be updated when the actual product and security posture materially change.
