ORBITBIZ · SECURITY

Security is part of the product.

OrbitBiz is designed around authenticated business workspaces and business-scoped access to operational data.

Authentication

OrbitBiz uses authenticated access for the private business workspace. Public product information remains separate from private business records.

Business-scoped data

Business data is associated with the relevant business workspace and protected by database access policies and membership checks.

Infrastructure

The application uses Supabase for authentication and PostgreSQL-backed application data, with Firebase Hosting delivering the web application.

Security is ongoing

Security is treated as an evolving engineering responsibility. Authentication, authorization, database policies, validation, transactional workflows and deployment configuration are reviewed as OrbitBiz grows.
